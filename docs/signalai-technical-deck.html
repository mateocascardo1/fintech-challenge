03 — Onboarding

Onboarding y Perfil de Riesgo

El onboarding determina el perfil de inversión del usuario y, opcionalmente, construye un portfolio inicial óptimo basado en sus preferencias.

Dos Flujos Posibles

Path A

Ya tengo portfolio

3 pasos: Inicio → Cargar posiciones (búsqueda de acciones/bonos) → Perfil de riesgo → Dashboard

Path B

Construir desde cero

8 pasos: Inicio → Perfil → Capital → Acciones → Bonos → Selección libre → Revisión → Dashboard

Builder Flow — Paso a Paso

1
¿Tenés portfolio?

El usuario elige entre cargar posiciones existentes o empezar de cero. UI animada con glassmorphism.

3

8 preguntas: horizonte, tolerancia al riesgo, objetivo, reacción a drawdown, patrimonio, liquidez, geografía, preferencia de bonos. + slider income vs growth (0-100).

4
Capital Inicial

Monto en USD con presets rápidos ($1K, $5K, $10K, $50K, $100K) o entrada custom.

5

6

ETFs de renta fija (BND, AGG, TLT, etc.) + bonos argentinos en vivo desde data912. Auto-skip si bond_preference = "none".

7

Buscador global (Yahoo + data912) para agregar cualquier instrumento adicional. Excluye los ya seleccionados.

8

Resumen visual: allocation por sleeve (equities, bonds, free, cash), montos USD por instrumento. Confirmar → crear posiciones en Supabase.

04 — Scoring Engine

Motor de Scoring del Portfolio

El Portfolio Score es un puntaje de 0 a 1000 que mide la calidad del portfolio en 4 dimensiones iguales. Cada sub-score vale hasta 250 puntos.

Fórmulas por Sub-Score

1. Diversificación

Mide la concentración del portfolio usando el Índice Herfindahl-Hirschman (HHI) en dos niveles:

positionHHI = Σ(weight_i²) sectorHHI = Σ(sector_weight_s²) avgHHI = (positionHHI + sectorHHI) / 2 score = (1 - avgHHI) × 250

Un portfolio con 1 activo tiene HHI = 1.0 (score = 0). Un portfolio perfectamente diversificado tiene HHI → 0 (score → 250).

2. Risk Match

Compara la beta y volatilidad del portfolio contra los targets del perfil de riesgo:

betaScore = max(0, 1 - |β_portfolio - β_target| / 0.5) volScore = max(0, 1 - |σ_portfolio - σ_target| / 0.2) score = ((betaScore + volScore) / 2) × 250
Risk ToleranceTarget βTarget σ
Conservative0.600.08
Moderate1.000.15
Aggressive1.300.22

3. Risk-Adjusted Return

Basado en el Sharpe Ratio del portfolio:

Sharpe = (R_portfolio - R_free) / σ_portfolio normalized = max(0, (Sharpe + 0.5) / 2.5) score = normalized × 250

Un Sharpe de 2.0 da score máximo (250). Un Sharpe negativo da score bajo.

4. Downside Protection

Combina correlación promedio y peso en activos defensivos:

correlationScore = max(0, 1 - avgCorrelation) defensiveScore = min(1, defensiveWeight / 0.4) score = (0.6 × correlationScore + 0.4 × defensiveScore) × 250

Sectores defensivos: Consumer Staples, Healthcare, Utilities. Asset types: bonds, bond ETFs, cash.

Adicionalmente, objective, investment_horizon, bond_preference, y geo_preference aplican ajustes incrementales sobre esta base. Los pesos se renormalizan a 100%.

Actual vs Modelo — Cómo se Compara

El API /api/portfolio/score clasifica cada posición en un bucket y calcula:

asset_type === "cash" → cash bucket asset_type === "bond" || "bond_etf" → bonds bucket ASSET_CLASS_MAP[symbol] ?? "us_equities" → equity buckets gap = model_pct - actual_pct (por bucket)

El gap por bucket se envía al modelo AI para generar recomendaciones de allocation.

06 — AI Insights

Diagnóstico y Recomendaciones

Cuando el usuario modifica su portfolio, se dispara la generación de insights AI que combinan análisis determinístico con inteligencia artificial.

Pipeline de Generación

TRIGGER Cambio en portfolio (POST /api/portfolio)
↓
STEP 1 Expire insights anteriores en Supabase
↓
STEP 2 Compute determinístico: scores, HHI, Sharpe, allocation gaps
↓
STEP 3 Prompt a Claude Sonnet 4 con datos duros + perfil
↓
STEP 4 Parse JSON → Insert rows en ai_insights

Estructura del Prompt

El prompt inyecta los datos determinísticos calculados server-side para que el modelo AI no invente números:

Sección del PromptContenido
PosicionesLista de symbol, quantity, asset_type
Score TotalN/1000 + 4 sub-scores /250
DiversificaciónHHI position, HHI sector, count de posiciones, largest position
RiesgoBeta vs target, vol vs target, Sharpe ratio
DefensivoDefensive weight, avg correlation
Allocation gapsActual % vs modelo % por bucket, con gap
PerfilRisk tolerance, horizon, objective, bond preference, geo
Bonos ARTop 15 instrumentos de renta fija por volumen (opcional)

Output del Modelo (JSON)

DIAGNOSIS

Diagnóstico

Exactamente 4 items, uno por sub-score. Título + body textual. El score_impact es el sub-score real (determinístico).

ALLOC_MOVES

Allocation Moves

2-4 movimientos de categoría. direction (increase/decrease), current_pct, target_pct, score_impact estimado por el modelo.

INSTRUMENT_PICKS

Picks

3-5 instrumentos. action (buy/sell), symbol, reason, priority, improves (qué sub-score mejora).

{ "diagnosis": [ { "category": "diversification", "title": "...", "body": "..." }, { "category": "risk_match", "title": "...", "body": "..." }, ... ], "allocation_moves": [ { "asset_class": "bonds", "direction": "increase", "current_pct": 15, "target_pct": 25, "score_impact": 40, ... } ], "instrument_picks": [ { "action": "buy", "symbol": "BND", "asset_type": "etf", "reason": "...", "score_impact": 30, "priority": "high", "improves": "downside_protection" } ] }

07 — AI Advisor

Investment Advisor (Chat)

El advisor es un agente conversacional con acceso completo al estado del usuario y herramientas de datos en tiempo real.

Contexto Inyectado al Advisor

A diferencia de un chatbot genérico, el advisor recibe el estado completo del portfolio antes de cada conversación:

👤

Perfil de Riesgo

Tolerancia, horizonte, objetivo, edad, preferencia de bonos, experiencia, ingreso mensual.

📋

Posiciones Actuales

Lista completa: symbol, quantity, asset_type para cada holding.

🎯

Portfolio Score

Total /1000 + 4 sub-scores /250 + allocation actual vs modelo por bucket.

🧠

AI Insights Activos

Diagnóstico (4 dimensiones), allocation moves (from/to %), instrument picks (buy/sell + impacto).

Filosofía de Asesoramiento

Objetivo principal: Mejorar el Portfolio Score del usuario.
Cada recomendación debe:
  1. Alinearse con el perfil de riesgo del usuario
  2. Cerrar brechas entre allocation actual y modelo
  3. Profundizar (no contradecir) el diagnóstico AI existente
  4. Indicar qué sub-score mejora y cuántos puntos estima
Persona: CFA Charterholder, español rioplatense, directo, con datos concretos.

Conversión ARS → USD (MEP)

Los bonos argentinos cotizan en ARS. SignalAI calcula el tipo de cambio MEP implícito comparando pares de bonos:

MEP = avg(ARS_clean_price / USD_clean_price) // Para cada par: AL30 (ARS) vs AL30C (USD), GD30 vs GD30C, etc. // Fallback: DEFAULT_MEP = 1200

Este rate se usa en: portfolio valuation, position card, sparkline histórica, scoring engine, y AI insights.

09 — End-to-End

Flujo Completo: Del Onboarding a los Insights

Cómo fluye la información desde que el usuario se registra hasta que recibe recomendaciones personalizadas.

A
Registro + Onboarding

Email/password → Supabase Auth → Wizard de onboarding. Se crean: profiles (perfil de riesgo) y positions (holdings). El perfil alimenta el modelo de allocation.

B
Dashboard Load

Al cargar el dashboard: se fetch posiciones, se calculan quotes (Yahoo + data912), se computa el Portfolio Score (4 sub-scores), y se cargan insights AI previos. Si no hay insights, se triggerean.

C
Modificación de Portfolio

Cuando el usuario agrega, elimina o modifica una posición → POST /api/portfolio → se expiran insights anteriores → se regeneran insights con el nuevo estado.

D
Generación de Insights AI

POST /api/insights → compute determinístico (scores, HHI, Sharpe, gaps) → prompt con datos + perfil → Claude Sonnet 4 → parse JSON (diagnosis + alloc_moves + picks) → insert en Supabase.

E
Dashboard Actualizado

Los componentes cargan los nuevos insights: Diagnóstico (4 cards con severity), Recomendaciones de Allocation (movimientos visuales), Picks de Instrumentos (buy/sell cards). El score se actualiza en tiempo real.

F
Advisor Chat (Opcional)

El usuario puede abrir el advisor en cualquier momento. El advisor recibe todo el contexto (perfil + posiciones + score + insights) y puede buscar datos live con tools. Cada respuesta está alineada con el diagnóstico y busca mejorar el score.
